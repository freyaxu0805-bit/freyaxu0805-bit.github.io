# Design — 个人网站设计说明

## 1. 页面结构与排列顺序

页面采用单页纵向滚动布局，从上到下依次为：

1. **Hero（首屏）** — 姓名 + 职位头衔 + 一句话定位
2. **About（关于我）** — 个人简介 + 插画风格头像
3. **Experience（经历）** — 新浪微博 + 浦发银行 实习经历（时间倒序）
4. **Education（教育）** — 深圳大学 管理科学与工程 硕士
5. **Projects（项目）** — 量化分析 + 市场调研 + 创协项目
6. **Skills（技能）** — 软件技能 + 英语（以"A Little More About Me"板块呈现）
7. **Contact / Footer（联系方式）** — 邮箱 + GitHub + LinkedIn

## 2. 配色方案

基于 Modern Resume Theme 默认配色，做少量个性化调整：

| 项目 | 取值 | 说明 |
|------|------|------|
| 主色 | 保持模板默认蓝色系 | 专业、可信赖 |
| 背景色 | #fff（浅色模式）/ 模板默认暗色（暗色模式） | |
| 正文字体 | 模板默认无衬线字体（系统字体栈） | |
| 标题字体 | 同正文，加粗处理 | |
| 强调色 | 主色加亮 | 链接、按钮悬停 |

暗色模式：关闭（darkmode: false），保持浅色简洁风格。

## 3. 文件映射（模板各文件对应什么）

| 文件 | 作用 | 修改方式 |
|------|------|----------|
| `_config.yml` | 核心配置文件 | 修改个人信息、项目、经历、技能等内容 |
| `index.md` | 首页入口 | 基本不变（仅引用 default 布局） |
| `_includes/header.html` | 顶部导航栏 | 不改 |
| `_includes/about.html` | 关于我板块 | 不改（内容由 _config.yml 驱动） |
| `_includes/footer.html` | 底部区域 | 不改 |
| `assets/` | 样式与脚本资源 | 不改 |
| `images/` | 图片资源 | 替换头像与项目配图 |
| `_sass/` | SCSS 样式文件 | 不改 |

## 4. 模板修改计划

### 修改的内容（在 _config.yml 中）
- 个人信息：name、title、email、website
- 社交链接：去掉不用的（Twitter、Dribbble、Facebook 等），只保留 GitHub + LinkedIn + email
- About 内容：替换为真实个人简介
- Experience：替换为新浪微博 + 浦发银行 两段实习
- Education：替换为深圳大学 管理科学与工程 硕士
- Projects：替换为三个真实项目
- A Little More About Me：替换为技能清单

### 保留不变的内容
- 整体布局与页面结构
- CSS 样式（不改 SCSS）
- Jekyll 配置（theme、plugins）
- 导航与页脚样式

### 删除/隐藏的内容
- 模板示例数据（占位项目名、虚拟公司名）
- 不使用的社交链接（Twitter、Dribbble、Facebook、StackOverflow 等）
- Google Analytics / GTM（不启用）

## 5. 响应式与移动端
- 模板已内置响应式设计，需在移动端验证：
  - 首屏文字完整显示，不截断
  - 经历和项目卡片宽度自适应
  - 社交图标在窄屏上正常排列

## 6. 图片与素材来源

| 素材 | 来源 | 说明 |
|------|------|------|
| 个人头像 | AI 生成插画风格头像 | 替代真人照片 |
| 项目配图 | Unsplash 免费图库 或 AI 生成 | 版权合规，与内容相关 |

## 7. 隐私说明
- 仓库不包含 .env、密码、API Key、Token 等敏感文件
- 不提交个人手机号、家庭住址
- .gitignore 已包含常见排除规则
