# PRD — 个人网站产品需求文档

## 1. 项目目标
构建一个个人简历网站，用于展示 Freya Xu 的教育背景、实习经历、项目经验与技能，面向未来的实习招聘方，传递"愿意尝试新技术、紧跟时代发展"的个人品牌形象。

## 2. 目标用户与场景

**优先级：面试官 > HR > 同行/校友**

| 用户 | 场景 | 需求 |
|------|------|------|
| 互联网/金融行业招聘 HR | 初步筛选简历 | 快速理解候选人背景、实习经历、技能匹配度 |
| 业务面试官 | 面试前深入了解候选人 | 查看项目细节、实习产出、技术能力、验证简历真实性 |
| 同行/校友 | 社交或学术交流 | 了解研究方向、合作可能性 |

## 3. 希望访客记住什么
- 愿意尝试新技术：在量化项目中使用 AI 工具协同编程、调用大模型 API 进行文本挖掘
- 具备前瞻应用意识：在金融数据分析和互联网商业运营中主动引入 AI 工具（大模型 API、AI 代码辅助），将前沿工具落地到实际业务场景
- 复合背景：兼具金融行业实践（银行对公、风控合规）与互联网经验（游戏行业广告运营、数据分析）

## 4. 页面内容板块

| 板块 | 内容 | 说明 |
|------|------|------|
| Hero（首屏） | 姓名 + 职位头衔 + 一句话简介 | 管理科学与工程硕士 / 互联网商业化 / AI 工具应用 |
| About（关于我） | 个人简介 + 头像 | 突出行业研究、数据分析、商业运营能力 |
关于头像：使用插画风格头像，替代真人照片，平衡专业感与个人辨识度 |
| Experience（经历） | 新浪微博 + 浦发银行 两段实习 | 每个岗位详细描述职责与产出 |
| Education（教育） | 深圳大学 管理科学与工程 硕士 | 含荣誉奖项与核心课程 |
| Projects（项目） | 量化分析 + 市场调研 + 创协项目 | 突出技术应用与商业思维 |
| Skills（技能） | 软件技能 + 英语能力 | 在 A Little More About Me 板块呈现 |
| Contact（联系方式） | 邮箱 + GitHub + 社交链接 | 便于招聘方联系 |

## 5. 不在范围内（明确排除）
- 不手写 HTML/CSS/JavaScript（使用模板配置驱动）
- 不接入数据库、后端服务或评论系统
- 不部署第三方服务器，仅托管于 GitHub Pages
- 不发布个人隐私信息（手机号、住址、身份证号、课程密码、API Key）

## 6. 完成标准
- [ ] 所有占位内容替换为真实个人数据
- [ ] 头像图片替换为真实合规头像
- [ ] 图片策略明确：头像使用插画风格，项目配图使用免费图库或 AI 生成
- [ ] 超链接可用（项目 GitHub、社交链接、联系方式）
- [ ] 所有链接跳转至正确目标页面，无 404 错误
- [ ] 移动端可正常浏览排版
- [ ] GitHub Pages 可公开访问
- [ ] 文档齐全（PRD / Design / Checklist / 最终报告 / 截图）

## 7. 隐私边界
- 可公开：姓名、教育背景、实习经历、项目经验、技能、GitHub 链接、邮箱
- 绝不公开：手机号、家庭住址、身份证号、课程密码、API Key、Token
